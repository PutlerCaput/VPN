## Что исключено из рабочей версии

- Старый раздел README о топологии Астана + Hetzner и команды для неё.
- `scripts/harden_host.sh`: сбрасывал UFW и создавал правила для старых ролей,
  не соответствующих описанной схеме Германия + Россия с DNAT.
- Неиспользуемый метод `ProvisioningService.activate_subscription`: платежи
  обслуживает существующий `process_paid_payment` с устойчивой очередью.
  Методы `_extend` и `add_bonus_days` сохранены: бонусный интерфейс используется
  тестами и сохраняет текущий тариф пользователя.
- Неиспользуемые алиасы `PRICES_RUB`, `PRICES_USDT`, `register_tma_routes` и один
  неиспользуемый импорт в тестах. Рабочие тарифы и общий REST API сохранены.
- Отдельный пакет `safety` и его необязательный дублирующий шаг CI. Проверки
  pip-audit, Bandit, secret scan, pre-commit и gitleaks сохранены.
- Исторические заявления о проверенных образах/отсутствии уязвимостей больше
  не представлены в README как доказательство текущей готовности.
- Ранее созданная папка `compliance/` для PostgreSQL вынесена из текущего проекта:
  приложение использует SQLite/SQLCipher, а требуемой PostgreSQL-таблицы нет.
  Это не отменяет задачу архивирования: её интеграция с реальной схемой пока
  не реализована. Исходники модуля сохранены отдельно для дальнейшей работы.

Сохранены все тесты, lockfile обоих приложений, PWA, Mini App, платежные
провайдеры, оферта, маркетинговые материалы, Xray routing и инструменты бэкапа.
PWA и Mini App имеют разные способы авторизации/хранения токенов и разные
платёжные сценарии, поэтому не признаны взаимозаменяемыми дубликатами.

## Сопутствующие исправления проверок

- Secret scan больше не сканирует `.venv/`, `venv/` и `.pytest_cache/`.
- Bandit исключает локальные зависимости и каталоги runtime-данных;
  исходники приложения продолжают проверяться.
- Для четырёх SQL-запросов задокументировано адресное исключение Ruff S608:
  имена столбцов строятся только после проверки роли по allowlist
  `inviter`/`invitee`; значения остаются параметризованными.
- Форматирование обновлённого кода приведено к настройкам проекта.
