# Фирменный стиль: логотип, цвета, шрифт

Редакция от 8 ноября 2026. Всё, что видит клиент, построено из одного файла —
`branding/cyberdefency-logo.webp`.

## Где показывается логотип

| Где | Что видит клиент | Файлы |
|---|---|---|
| Бот, `/start` нового клиента | Картинка с логотипом перед приветствием и офертой. Приходит, пока клиент не принял оферту; потом не показывается | `branding/telegram/welcome-1280x720.jpg` |
| Аватар и описание бота | Загружаются вручную в @BotFather, см. ниже | `branding/telegram/avatar-640.jpg`, `branding/telegram/description-640x360.jpg` |
| Mini App | Эмблема и название в шапке; логотип на экранах загрузки и ошибок | `tma/public/brand/`, `tma/public/icons/` |
| Сайт | Логотип на экране входа, эмблема в шапке, иконки на телефоне и во вкладке | `pwa/public/brand/`, `pwa/public/icons/` |
| Превью ссылки на сайт | Баннер 1200×630 в Telegram, WhatsApp, VK | `pwa/public/brand/og-image.jpg` |
| Оферта и политика | Отдельные страницы: шапка, оглавление, на телефоне таблицы превращаются в карточки. Текст берётся из `legal/*.md` | `scripts/legal_page/` |
| Страница подключения | Шапка с эмблемой | `pwa/public/connect.html` |

## Цвета

Одна тёмная тема в цветах логотипа. Mini App просит Telegram покрасить в цвет
фона свою шапку, фон и нижнюю панель, чтобы сверху и снизу не было светлых полос.

| Назначение | Цвет |
|---|---|
| Фон | `#050a14` |
| Карточки | `#0d1a30` |
| Основной текст | `#e8f1ff` |
| Второстепенный текст | `#8ea4c2` |
| Ссылки | `#6fd0ff` |
| Акцент | `#2ec5ff` |
| Основная кнопка | градиент `#38d0ff → #2f8cff`, текст `#04111f` |
| Успех, внимание, ошибка | `#34d399`, `#fbbf24`, `#f87171` |

Контраст основного текста с фоном — 17:1, второстепенного с карточкой — 6,8:1.
Это выше требования WCAG AA (4,5:1).

## Шрифт

Manrope, лицензия SIL Open Font License 1.1 (текст лицензии лежит рядом со
шрифтом, в `fonts/OFL.txt`). Шрифт отдаёт наш сервер, запросов к Google нет.
Три файла woff2 — кириллица, латиница и дополнительные знаки вроде ₽ — весят
вместе около 55 КБ. Браузер скачивает только те, что нужны на странице.

Оферта и политика набраны кеглем 17 px с межстрочным интервалом 1,7: длинный
текст так легче читать с телефона.

## Как заменить логотип

1. Положите новый файл вместо `branding/cyberdefency-logo.webp`. Нужен квадрат,
   лучше 2000×2000.
2. Если щит в новом файле стоит в другом месте, поправьте `EMBLEM_BOX` в
   `scripts/build_brand_assets.py`. Это квадрат со щитом без надписи: на иконках
   от 32 до 192 px надпись не читается, поэтому там только щит.
3. Пересоберите картинки и проверьте их:

   ```bash
   pip install -r requirements-dev.txt     # один раз: скрипту нужен Pillow
   python scripts/build_brand_assets.py
   pytest -q tests/test_brand.py
   ```

4. Закоммитьте изменённые файлы, обновите бота и сайт (`update_bot.sh`,
   `update_web.sh`) и заново загрузите картинки в @BotFather.

## Что сделать вручную в @BotFather

Эти картинки Telegram не берёт из кода. Файлы лежат в `branding/telegram/`, на
сервере — в `/root/vpn-src/branding/telegram/`.

1. **Аватар.** `/mybots` → бот → Edit Bot → Edit Botpic → отправьте
   `avatar-640.jpg`.
2. **Картинка описания.** Её видят в пустом чате до нажатия «Старт».
   Edit Bot → Edit Description Picture → `description-640x360.jpg`. Telegram
   принимает ровно 640×360.
3. **Экран загрузки Mini App.** Bot Settings → Configure Mini App → Enable
   Mini App, адрес тот же, что у кнопки меню. Там же настраиваются иконка и
   цвета экрана загрузки: цвет фона — `#050a14` и для светлой, и для тёмной темы.
   Иконку меняйте, только если BotFather принимает PNG
   (`tma/public/icons/icon-512.png`). Если он просит SVG, оставьте стандартную.
4. **Превью ссылки.** Telegram запоминает превью сайта. Чтобы он показал новый
   баннер, отправьте ссылку `https://app.cyberdefency.com/` боту @WebpageBot.

## Адрес сайта в превью и документах

Картинка превью и ссылки в оферте должны содержать полный адрес сайта.
`update_web.sh` берёт его из `PUBLIC_BASE_URL` работающего бота и передаёт в
сборку. Если адрес не похож на `https://имя.домен`, используется
`https://app.cyberdefency.com`. После смены адреса
(`update_bot.sh --set-public-url`) запустите `update_web.sh` ещё раз.

## Проверка после обновления сайта

```bash
curl -s https://app.cyberdefency.com/ | grep -o 'og:image" content="[^"]*"'   # полный адрес картинки
curl -sI https://app.cyberdefency.com/brand/og-image.jpg | head -n1          # 200
curl -sI https://app.cyberdefency.com/oferta | grep -i '^content-type'       # text/html
```

Оферта и политика открываются оформленными страницами. В подвале каждой есть
ссылка «Скачать .md» с исходным текстом.
