# Подключение чеков ЮKassa к «Мой налог»

## Что уже умеет бот

Для режима самозанятого (`YOOKASSA_RECEIPT_MODE=self_employed`) бот создаёт
платёж в ЮKassa с названием услуги и суммой. ЮKassa должна быть отдельно
подключена к «Мой налог» в кабинете магазина: после успешной оплаты именно
эта интеграция передаёт сведения о доходе и формирует чек. Бот не отправляет
чек напрямую в ФНС и не хранит пароль от «Мой налог».

В тестовом магазине из текущей облачной среды проверка ЮKassa прошла, магазин
активен (`test=true`, `status=enabled`), но API вернул
`fiscalization_enabled=false`. Значит, автоматическая фискализация для этого
магазина пока не подтверждена. Платежи и настройки магазина этим запросом не
менялись.

## Что сделать владельцу в кабинете

1. Войдите в личный кабинет ЮKassa и выберите нужный магазин. Для проверки
   сначала подключите тестовый магазин; боевой магазин настраивается отдельно.
2. Откройте раздел настроек чеков/фискализации магазина. Выберите вариант для
   самозанятого и интеграцию с приложением «Мой налог».
3. Нажмите подключение и авторизуйтесь в «Мой налог» через официальный экран.
   Подтвердите передачу сведений о доходах ЮKassa. Не присылайте коды входа,
   пароль, ключи или скриншоты с персональными данными в чат.
4. В ЮKassa убедитесь, что подключение активно и чеки формируются автоматически
   для успешных платежей. Название услуги в чеке бот передаёт в описании платежа:
   «Информационно-техническая услуга «Сервис защищённого доступа», N мес.». Это название
   из п. 1.1 оферты, без слова «тариф»; клиент видит его и в банке как назначение платежа.
   Меняется одной строкой `SERVICE_NAME` в `services/yookassa.py` (тест сверяет её с
   офертой). Счета, созданные до обновления, остаются со старым текстом.
5. Повторная проверка API магазина должна показать `fiscalization_enabled=true`.
   Если поле остаётся `false` или такого пункта нет, остановитесь и обратитесь
   в поддержку ЮKassa: настройка может быть недоступна для статуса или типа
   магазина.

Названия разделов могут отличаться в интерфейсе ЮKassa. Не выбирайте режим
онлайн-кассы для ИП/ООО вместо режима самозанятого: это другой тип фискализации.

## Перед включением на боевом боте

- Настройте и отдельно проверьте боевой магазин; тестовая настройка не включает
  фискализацию на боевом.
- Для бота должны быть указаны `SBP_PROVIDER=yookassa`, правильный `YOOKASSA_SHOP_ID`,
  секретный ключ именно этого магазина и `YOOKASSA_RECEIPT_MODE=self_employed`.
- Публичный webhook `payment.succeeded` должен доходить до немецкого сервера.
  Иначе чек может сформироваться у ЮKassa, но бот не продлит подписку.
- Не проводите реальный платёж для проверки без согласования суммы и возврата.

Подготовительная проверка магазина в `scripts/prepare_yookassa.py` теперь
отказывает в подготовке, пока API не подтвердит включённую фискализацию.
