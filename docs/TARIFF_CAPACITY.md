# Ёмкость тарифа «Стандарт» (16.11.2026)

Тариф: 2 устройства, **100 ГБ на 30 дней** (было 200), цены без изменений (299 ₽ за 30 дней).

## Исходные данные

- Один сервер: 1 vCPU, 2 ГБ RAM, Хельсинки (HOSTKEY). Резервного нет.
- Месячный лимит трафика хостинга: в боте по умолчанию 5000 ГБ (`SERVER_TRAFFIC_LIMIT_GB`).
  **Реальный лимит тарифа HOSTKEY не проверен** — уточнить в панели хостинга.
- Через прокси каждый гигабайт пользователя проходит дважды (вход и выход), поэтому из
  5 ТБ на пользователей остаётся ~2,5 ТБ.

## Расчёт

- Худший случай: все выбирают лимит полностью — 2,5 ТБ / 100 ГБ = **25 подписчиков**
  (при 200 ГБ было бы 12).
- Реалистично: средний расход 20–30% лимита — **около 60–80 подписчиков**.
- CPU и RAM: 1 vCPU тянет VLESS Reality на десятки одновременных подключений; узкое место —
  RAM (см. `HIDDIFY_MIGRATION.md`).

## Рекомендация

Продавать до ~50 активных подписок. При 70% месячного трафика (бот предупреждает) или
постоянном swap — переходить на 4 ГБ RAM / второй сервер, и только потом поднимать лимиты.
