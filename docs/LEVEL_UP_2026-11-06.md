# Сравнение с крупными VPN-сервисами (уровень NordVPN) — 6 ноября 2026

Задача владельца: «улучшить проект до уровня NordVPN». Ниже — честное
сравнение по возможностям, что сделано в коде и что упирается не в код, а в
серверы, деньги и юридическую сторону. Характеристики крупных сервисов описаны
в общих чертах по их публичным материалам; точные цифры у них меняются.

## 1. Сравнение

| Возможность крупного сервиса | Было | Стало | Что ещё нужно |
|---|---|---|---|
| Много стран и серверов | 1 сервер (DE) + relay RU | Ссылка-подписка со всеми серверами Hiddify Manager; новый сервер появляется у клиентов сам, без переустановки | **Серверы.** Каждая локация — отдельный VPS с Hiddify Manager-node (по сценарию владельца около 1500 ₽/мес за узел) |
| Список серверов со статусом | нет | `/servers` в боте, карточка «Серверы» в PWA и Mini App | — |
| Мониторинг и реакция на сбой | нет | Проверка панели и узлов каждые 2 мин, уведомление владельцу после 2 неудачных проверок подряд и при восстановлении, предупреждение пользователям в `/status` | Внешний мониторинг с другого сервера (если упал весь DE, бот тоже недоступен) |
| Автопродление подписки | нет | Ежемесячная подписка Telegram Stars, отключение в один клик (`/autorenew`), каждое списание зачисляется ровно один раз | Включить после публикации оферты (п. 3.3.1) |
| Kill switch / автоподключение | нет | Инструкция «🛡 Защита при обрыве»: системная блокировка Android и рекомендации для других систем | Собственные приложения (см. ниже) |
| Блокировка вредоносных сайтов (Threat Protection) | есть (фильтр Xray) | без изменений | Блокировка рекламы и трекеров — отдельный выбор: ломает часть сайтов, нужна отдельная настройка на узле |
| Обфускация против блокировок | есть (VLESS + XTLS-Reality) | без изменений | Гарантировать работу в любой сети нельзя никому |
| Учёт трафика и устройств | был (лимит устройств только в оферте) | 2 устройства, 200 ГБ / 30 дней, сброс ссылки | Техническое ограничение устройств Hiddify Manager не поддерживает |
| Без журналов действий | по умолчанию журналы выключены | без изменений | Независимый аудит — платная услуга аудиторской компании |
| Свои приложения в магазинах | нет (клиенты v2rayNG, Streisand, Hiddify) | без изменений | Разработка и публикация собственных приложений, аккаунты разработчика в магазинах, юрлицо |
| Мультихоп, выделенный IP, Meshnet | нет | без изменений | Отдельные серверы и IP-адреса; в оферте прямо указано, что не предоставляется |
| Поддержка 24/7 | бот-переадресация владельцу | без изменений | Люди на сменах |
| Гарантия возврата | п. 6.3 оферты | возврат звёзд через `/refund` | Политику возврата определяет владелец с юристом |

Вывод: по удобству и надёжности для пилота на 10–20 человек код теперь
закрывает основные ожидания пользователя крупного сервиса. Масштаб крупного
сервиса — это прежде всего серверы в разных странах, собственные приложения,
аудиты и команда; это решения о бюджете и юридической модели, а не правки кода.

## 2. Как включить новое (после установки обновления по UPDATE_2026-11-06.md)

Все команды — в PowerShell на ПК. Скрипт меняет только перечисленные строки
`.env`, перезапускает лишь бота и сам возвращает прежний `.env`, если бот не
стал healthy.

**Ссылка-подписка со всеми серверами.** Сначала откройте на телефоне через
мобильный интернет **без VPN** адрес `https://sub.cyberdefency.com:8443` —
должна открыться любая страница или ошибка от сервера, а не «сайт недоступен».
Если адрес недоступен из сетей пользователей, клиенты не смогут обновлять
подписку: оставьте прежний режим `link`.

```powershell
ssh root@89.125.210.172 'bash /root/vpn-update/*/scripts/update_bot.sh --set CONFIG_DELIVERY=subscription SUBSCRIPTION_BASE_URL=https://sub.cyberdefency.com:8443 MAIN_LOCATION_NAME=Germany'
```

Новая ссылка выдаётся пользователю при следующем открытии «🔐 Моя
конфигурация»; уже импортированные одиночные ссылки продолжают работать.

**Автопродление** — после публикации оферты с п. 3.3.1:

```powershell
ssh root@89.125.210.172 'bash /root/vpn-update/*/scripts/update_bot.sh --set STARS_AUTORENEW_ENABLED=true'
```

**Новый сервер (локация).** Устанавливается на отдельном VPS как Hiddify Manager-node и
подключается в панели Hiddify Manager (Nodes). Бот увидит его автоматически: он
появится в `/servers`, а в ссылке-подписке — после настройки хоста в панели.
Это работа на серверах, её нужно выполнять с сохранённой резервной копией и
не трогая действующий AmneziaWG.

## 3. Как устроено

- `services/health.py` — опрос `/api/core` (основной сервер) и `/api/nodes`
  (дополнительные узлы) панели Hiddify Manager; узлы, выключенные владельцем
  (`disabled`), не показываются. Данные пользователей не читаются.
- `services/provisioning.py::_config_from` — выбор между одиночной ссылкой и
  ссылкой-подпиской; если панель не дала пригодный адрес подписки, остаётся
  одиночная ссылка.
- `services/stars.py` — подписки: payload `sub:<id>`, каждое списание —
  отдельная запись платежа с уникальным ID списания Telegram; обновления
  `BotSubscriptionUpdated` (отмена, повторное включение, неудачное списание);
  сверка через `getStarTransactions`; при возврате или бане автопродление
  отключается.
- Тесты: `tests/test_locations.py`, `tests/test_autorenew.py`.

## 4. Ограничения, о которых нужно помнить

- Сброс счётчика трафика, выбор сервера и автоподключение выполняет клиентское
  приложение пользователя; бот ими не управляет.
- Если сервер DE недоступен целиком, бот, панель и мониторинг недоступны
  вместе с ним. Для настоящего уровня надёжности нужен внешний мониторинг и
  резервный сервер бота.
- Подписка Telegram Stars поддерживает только период 30 дней (ограничение
  Telegram). Длинные периоды оплачиваются разово.
