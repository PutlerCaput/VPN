# Оплата внутри Telegram: Telegram Stars

Актуально на 6 ноября 2026 года. Правила Telegram проверены по первоисточнику:
<https://core.telegram.org/bots/payments-stars>.

## Что требует Telegram

- Цифровые товары и услуги, которые продаются **внутри** бота или Mini App,
  оплачиваются только в Telegram Stars (валюта `XTR`). Подписка на подключение —
  цифровая услуга.
- Telegram может не показывать мобильным пользователям бота, который продаёт
  цифровое через сторонних провайдеров или в других валютах.
- Бот обязан отвечать на `/paysupport` (споры по оплате), `/support` и `/terms`.
  Пользователь должен принять условия до покупки.
- На `pre_checkout_query` бот отвечает за 10 секунд, иначе Telegram отменяет платёж.
- `telegram_payment_charge_id` нужно хранить: по нему делается возврат.

## Что реализовано

| Шаг | Где | Что происходит |
|---|---|---|
| Заказ | `services/billing.py` (`method="stars"`) | Заказ в БД с ценой в целых звёздах. Повторное нажатие в течение суток выставляет тот же неоплаченный заказ. |
| Счёт | `handlers/payments.py` (`send_stars_invoice`) | `sendInvoice` в чате: `currency=XTR`, без provider token, payload = номер заказа. |
| Проверка | `stars_pre_checkout` → `StarsPayments.checkout_error` | Заказ принадлежит этому пользователю, ещё не оплачен, не старше 48 ч, сумма и валюта совпадают, нет бана, оферта принята. |
| Зачисление | `stars_successful_payment` → `record_success` | ID списания Telegram привязывается к заказу (уникально), затем та же очередь активации, что у ЮKassa: срок продлевается ровно один раз. |
| Страховка | задача `stars_reconciliation` (каждые 5 мин) | `getStarTransactions`: если сообщение об оплате потерялось или обработка упала, оплаченный заказ всё равно зачисляется. |
| Возврат | `/refund <номер заказа>` (админ, при `ADMIN_TELEGRAM_READ_ONLY=false`) | `refundStarPayment`, заказ → `refunded`, оплаченный период снимается с подписки. Сообщение Telegram о возврате обрабатывается так же и не снимает период второй раз. |
| Споры | `/paysupport`, `/terms` | Вопрос по оплате уходит владельцу с пометкой; заблокированный пользователь может написать `/paysupport <текст>` одной строкой. |

Антифлуд и фильтр заблокированных пользователей не отбрасывают служебные
сообщения об оплате: деньги уже списаны, запись нужна для проверки или возврата.

## Настройки

```env
STARS_ENABLED=true
# 299 ₽ / 1.60 = 187 ⭐ (округление вверх до целой звезды)
STARS_RUB_PER_STAR=1.60
# Скрыть кнопку ЮKassa в боте; оплата на сайте (PWA) от этого не зависит
YOOKASSA_IN_BOT=false
```

Ключи для Stars не нужны: счёт выставляет сам бот. Курс — решение владельца.
Пользователь обычно покупает звёзды у Telegram дороже, чем их потом можно вывести,
поэтому при `1.60` пользователь платит примерно цену тарифа в рублях, а
владелец получает меньше. Проверьте фактическую стоимость покупки и вывода
звёзд, налоговый учёт такого дохода и доступность покупки звёзд для ваших
пользователей до массовых продаж.

## Почему не используется токен ЮKassa из @BotFather

Подключение ЮKassa «через официального бота» (BotFather → Payments) выдаёт
токен Telegram Payments для сторонних провайдеров. По правилам Telegram этот
путь не предназначен для цифровых услуг внутри бота, поэтому код его не
использует, и в настройках нет поля для такого токена. Не вставляйте его в
`.env` или `secrets/`.

Рубли через ЮKassa по-прежнему работают через REST API (`SBP_PROVIDER=yookassa`,
`YOOKASSA_SHOP_ID`, `secrets/yookassa_secret_key.txt`): страница оплаты ЮKassa,
проверка платежа повторным чтением API, сверка. Эти ключи выдаются в личном
кабинете ЮKassa (раздел ключей API), это не токен из BotFather. Где именно
показывать рублёвую оплату (сайт вне Telegram или бот), решает владелец с учётом
правил Telegram; бот по умолчанию в новой конфигурации её не показывает.

## Как проверить после установки

1. `/start` → «💳 Оплата» → «⭐ Telegram Stars» → тариф → срок. Должен прийти счёт.
2. Оплатить минимальный тариф своим аккаунтом. Бот пишет «✅ Оплата получена»,
   `/status` показывает новый срок.
3. `/refund <номер заказа>` с ПК (режим управления) — звёзды возвращаются,
   срок уменьшается на оплаченный период.

Локальные тесты (`tests/test_stars.py`) покрывают эти шаги с поддельным Telegram,
но не заменяют проверку настоящего платежа.
