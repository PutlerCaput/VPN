# Приложения для подключения: что предлагаем и почему

Редакция от 10 ноября 2026. Список один на три места: бот (`services/connection_guide.py`),
сайт (`pwa/src/device.ts`) и Mini App (`tma/src/device.ts`, шаги в `tma/src/i18n/ru.ts`).
Тесты (`tests/test_connect_screen.py`) не дают им разойтись и закрепляют ссылки установки
за официальными страницами.

## Правила отбора

Приложение попадает в список, только если выполнено всё:

1. **Бесплатное.** С 2 апреля 2026 Apple не принимает платежи в России, платные приложения
   и подписки внутри приложений недоступны.
2. **Открытый код и живой проект.** Репозиторий не в архиве, свежий релиз за последний год.
3. **Страница разработчика.** Ссылка ведёт на официальный раздел Releases или на само
   приложение в App Store (по номеру, не по названию: по имени ищутся двойники).
4. **Для App Store: есть в российской витрине.** Проверяется по публичному API Apple.
5. **Умеет добавлять подписку по ссылке** и работает с нашим узлом (VLESS Reality).

Чего сервис не советует: чужие Apple ID, сторонние магазины, непроверенные сборки. Если
приложения нет в магазине пользователя, он пишет в поддержку; подмены магазина мы не предлагаем.

| Система | Приложения | Где берут |
|---|---|---|
| Android | v2rayNG, NekoBox | GitHub Releases |
| iPhone / iPad | Karing, OneXray | App Store |
| Windows | v2rayN | GitHub Releases |

Что известно о каждом:

- **v2rayNG** (`2dust/v2rayNG`): GPL, 65 тыс. звёзд, не в архиве. Официальная страница в README одна, GitHub.
- **NekoBox** (`MatsuriDayo/NekoBoxForAndroid`): не в архиве, по данным поиска релиз 1.4.2 в феврале 2026
  (точнее покажет `scripts/check_client_apps.py`). В README
  сказано, что версию из Google Play с мая 2024 контролирует третья сторона: ставить только с GitHub.
- **Karing** (`KaringX/karing`): в российском App Store есть, версия 1.2.25 от 11.09.2026, 363 оценки, 3,99;
  выпущен в декабре 2023. Основан на sing-box, поддерживает подписки.
- **OneXray** (`OneXray/OneXray`): GPL-3.0, в российском App Store есть, версия 26.11.2 от 07.11.2026,
  148 оценок, 3,61; выпущен в мае 2025. Основан на Xray-core, как и наш узел. Есть собственная
  документация (`onexray.com/docs`), по ней написаны шаги.
- **v2rayN** (`2dust/v2rayN`): Windows, Linux и macOS, не в архиве, ветка 7.x выходит в 2026 году. Сборка
  для macOS не подписана: система пугает «приложение повреждено», в шагах есть команда из вики разработчика.

## Российские сайты напрямую (раздельное туннелирование)

Под инструкцией каждого приложения есть кнопка «🇷🇺 Российские сайты напрямую» (в боте),
на сайте и в Mini App это раскрывающийся блок под шагами. Тот же ответ бот даёт на вопросы
вроде «не открываются Госуслуги» (тема FAQ `direct`). Банки, Госуслуги, маркетплейсы и другие
российские сайты идут напрямую через провайдера клиента, остальное через сервер.

**Почему только в приложении.** Трафик, который уже дошёл до сервера, выходит в интернет
с его немецкого адреса, поэтому правило «российское напрямую» на сервере ничего не даст:
сайт всё равно увидит зарубежный адрес. Решать, что пускать мимо сервера, может только
приложение на устройстве. Сервер и подписка не меняются, правила включает сам клиент и сам
может их выключить (последний шаг каждой инструкции).

| Приложение | Чем пользуемся | Откуда шаги |
|---|---|---|
| v2rayNG | встроенный набор правил «Белый список России»: `geosite:category-ru` и `geoip:ru` напрямую, локальная сеть напрямую, торренты напрямую, QUIC закрыт | файлы приложения (`custom_routing_white_russia`, русские строки) |
| NekoBox | свой маршрут: `geosite:category-ru` и `geoip:ru` → прямое соединение | русские строки и экран маршрута приложения |
| Karing | «Разделение» → «Страна и регион» → Россия, у правил `geosite:ru`/`geoip:ru` действие «Прямое подключение» | документация Karing (karing.app/ru/tutorial/diversion) |
| OneXray | «Routing» → «Smart Routing» → «Direct region» = Russia | документация OneXray (onexray.com/docs/connect/smart-routing) |
| v2rayN | «Настройка региональных пресетов» → «Россия», маршрутизация «Всё, кроме РФ» (правила runetfreedom: `geoip:ru` и `geosite:ru-available-only-inside` напрямую) | русские строки v2rayN и описание пресета его автором |

Для прямых соединений шаги советуют DNS Яндекса (77.88.8.8), чтобы адреса российских сайтов
определялись в России. Клиент проверяет результат сам: на yandex.ru/internet его обычный адрес,
на ifconfig.me адрес сервера. В тексте сказано и о цене: шифрование сервиса на прямые
соединения не действует.

Тексты одинаковы в трёх местах (`services/connection_guide.py`, `pwa/src/device.ts`,
`tma/src/i18n/ru.ts`), за этим следит `tests/test_connect_screen.py`. В них нет слов «обход»,
VPN и proxy: правило проверки текстов сайта в CI. Поэтому пункт NekoBox назван «второй пункт
списка: прямое соединение».

## Как проверить сейчас

```bash
cd /root/vpn-src
python3 scripts/check_client_apps.py
```

Скрипт спрашивает Apple (российскую витрину) и GitHub (архив, дата последнего релиза) по каждому
приложению из меню и печатает `OK`, `WARN` или `PROBLEM`. `PROBLEM` значит: приложение больше нельзя
предлагать, уберите его из трёх мест списка. `WARN` значит, что проверить не удалось (нет сети, лимит
GitHub) или у проекта давно не было релиза. Запускайте раз в квартал и после новостей об удалении
приложений. Вручную одно приложение из App Store проверяется так (`resultCount` 1 есть, 0 нет):

```bash
curl -s "https://itunes.apple.com/lookup?id=6472431552&country=ru&entity=software"
```

## Что не проверено

Приложения не запускались на устройствах. Названия пунктов в шагах взяты из документации
разработчиков (OneXray, Karing, v2rayN) и руководств сообщества (v2rayNG, NekoBox) и меняются
между версиями: перед выкладкой пройдите по шагам на своём телефоне и компьютере.

То же относится к шагам «Российские сайты напрямую». Меньше всего уверенности в Karing:
названия правил после выбора страны документация не приводит. Если пункт называется иначе,
поправьте текст в трёх местах, тест подскажет, если они разойдутся.

Риски остаются. Apple может убрать и эти приложения: в 2025 году по требованию Роскомнадзора
убрано около 1200 приложений. С мая 2026 у части пользователей GitHub открывается нестабильно
(официальной блокировки нет): страница установки может не открыться, и тогда нужна поддержка.

## Как поменять список

1. Измените `services/connection_guide.py`, `pwa/src/device.ts`, `tma/src/device.ts` и
   `tma/src/i18n/ru.ts`.
2. Обновите таблицу выше и дату проверки.
3. `pytest tests/test_connect_menu.py tests/test_connect_screen.py tests/test_check_client_apps.py`:
   тесты скажут, если три места разошлись или вернулось убранное приложение.
