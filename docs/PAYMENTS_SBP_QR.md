# Оплата СБП по QR-коду (без страницы ЮMoney)

Актуально на 13 ноября 2026 года.

## Что случилось

С 7 ноября рубли принимаются только через СБП: бот создаёт платёж ЮKassa с
`payment_method_data {"type": "sbp"}` и сценарием подтверждения `redirect`.
ЮKassa отвечает ссылкой на свою страницу оплаты
`yoomoney.ru/checkout/payments/v2/contract/sbp?orderId=...`.

Эта страница — пустая оболочка: QR-код и список банков рисует приложение,
которое она загружает с CDN ЮMoney `static.yoomoney.ru`. Владелец проверил с
телефона 12 ноября:

- ссылка на страницу оплаты отвечает `HTTP 200`, заказ жив («Не оплачен»), в
  журнале бота ошибок нет — бот и наши серверы в порядке;
- `static.yoomoney.ru` по DNS телефона указывает на узел CDN 80.92.207.16
  (Иркутск), который не принимает соединения: `Connection timed out`. Узел в
  Москве (194.186.91.126) работал, с сервера в Германии CDN открывался;
- итог на телефоне — белый экран и бесконечная загрузка, с VPN и без, в
  браузере и в Telegram. С ПК через VPN оплата раньше проходила: вероятно,
  страница грузилась через другой узел CDN, который в тот момент отвечал.
  Какой узел достанется плательщику, зависит от его сети, поэтому способ
  «страница ЮMoney» ненадёжен для части плательщиков.

Узел CDN выбирает ЮMoney, а не бот. Повлиять на него мы можем только
обращением в поддержку ЮKassa.

## Что сделано

ЮKassa поддерживает для СБП второй сценарий подтверждения — `qr`
(спецификация API: `ConfirmationDataQr`, параметр `return_url` «доступно только
для платежей через СБП»). В нём ЮKassa отвечает не адресом своей страницы, а
самой ссылкой СБП `https://qr.nspk.ru/...` (`confirmation.confirmation_data`).

С настройкой `YOOKASSA_CONFIRMATION=qr`:

- бот присылает картинку с QR-кодом СБП (рисует её сам) и кнопки
  «🏦 Открыть приложение банка» и «🔄 Проверить оплату»;
- на телефоне кнопка открывает приложение банка (ссылка СБП, без страницы
  ЮMoney); на компьютере QR-код сканируют камерой телефона или в приложении
  банка;
- после оплаты приложение банка возвращает в бота (`return_url`), срок
  продлевается автоматически, как и раньше: бот опрашивает ЮKassa;
- открытый счёт («У вас уже есть неоплаченный счёт») показывается с тем же
  QR-кодом;
- на сайте (PWA) страница оплаты показывает QR-код и ту же кнопку.

Оплата по-прежнему только через СБП, ввода карты нет. Комиссия, чеки «Мой
налог», проверка оплаты и возвраты не меняются.

По умолчанию остаётся `redirect` (страница ЮMoney): переключение делает
владелец одной командой, и она сначала проверяет магазин.

Состояние на 13 ноября 2026: включено на боевом боте, проверка магазина прошла
(`PAYMENT_QR_CHECK_OK`, ссылка `qr.nspk.ru`), владелец оплатил через бота.

## Как включить

На DE, в папке с ботом, после обновления бота до этой версии:

```bash
bash scripts/update_bot.sh --set YOOKASSA_CONFIRMATION=qr
```

Команда сначала создаёт в магазине тестовый платёж на 10 ₽ со сценарием `qr` и
смотрит ответ ЮKassa. Переключает бота, только если пришла ссылка СБП:

```text
PAYMENT_QR_CHECK_OK: YooKassa returns an SBP link; the bot can show the QR code itself
...
SET_OK YOOKASSA_CONFIRMATION
```

Если ЮKassa отказала (`PAYMENT_QR_CHECK_FAILED: ... HTTP 400 ...`), ничего не
меняется: бот работает как раньше. Тестовый платёж никто не может оплатить:
ссылка нигде не показывается и не сохраняется, ЮKassa отменит его в течение
часа (в личном кабинете он будет виден как отменённый).

Только проверка, без переключения:

```bash
bash scripts/update_bot.sh --payment-qr-check
```

Текущий режим показывают `--payment-status` (`"sbp_confirmation"`) и
`--doctor` (строка `SBP by QR` или `SBP through the YooMoney checkout page`).

## Как проверить настоящей оплатой

1. В боте: «💳 Оплата» → рубли → тариф → срок. Должна прийти картинка с
   QR-кодом и кнопкой «🏦 Открыть приложение банка».
2. С телефона: нажать кнопку, выбрать банк, оплатить. Либо с ПК: открыть
   приложение банка на телефоне → оплата по QR → навести камеру на код.
3. Бот пишет «✅ Оплата получена», `/status` показывает новый срок.

Счёт, выставленный до переключения, сохраняет свою ссылку на страницу ЮMoney
и сам отменяется через час; его можно отменить кнопкой «❌ Отменить счёт» и
выбрать срок заново.

## Как вернуть страницу ЮMoney

```bash
bash scripts/update_bot.sh --set YOOKASSA_CONFIRMATION=redirect
```

Проверка для возврата не нужна. Уже выставленные счета с QR-кодом остаются
рабочими до оплаты или отмены.

## Обращение в поддержку ЮKassa (по желанию)

Узел CDN `static.yoomoney.ru` 80.92.207.16 не принимает соединения на 443, из-за
чего страница оплаты СБП у части плательщиков не загружается (белый экран).
Это стоит сообщить поддержке ЮKassa: с QR-сценарием бот от этого узла уже не
зависит, но сайт оплаты ЮMoney нужен, например, при возврате к сценарию
`redirect`.
