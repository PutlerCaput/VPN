# Настройка на Android и Windows

📱 **Android — v2rayNG**
1. Установите v2rayNG из Google Play или с GitHub проекта.
2. В боте: «🔐 Моя конфигурация» → скопируйте ссылку.
3. v2rayNG → «+» → «Импорт из буфера обмена».
4. Нажмите на кнопку подключения внизу экрана. Готово ✅

💻 **Windows / macOS / Linux — Nekoray**
1. Скачайте Nekoray с официальной страницы проекта на GitHub.
2. «Сервер» → «Добавить профиль из буфера обмена».
3. Правой кнопкой по профилю → «Запустить».
4. Включите «Режим TUN», чтобы шифровались все приложения. Готово ✅

⚠️ Скачивайте клиенты только из официальных источников.
